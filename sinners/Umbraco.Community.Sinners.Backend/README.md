# Umbraco.Community.Sinners

If you are reading this on NuGet, something has gone terribly wrong, because this package
was never published — deliberately.

Sinners enforces the **10 UmbraCommandments**: a set of opinionated Umbraco architecture
rules built as the live demo for a conference talk. It audits your installation on a
Penance Board, folds sinful compositions into page types, reorganizes your document types,
and contains at least one management API endpoint that edits your `.csproj` from a web
request. That last part is not a typo.

It is development-time talk-ware. Not for production. Not for staging. Barely for
development. Point it only at sites you are prepared to lose, which is also — fittingly —
the first commandment.

Full sermon, warnings, and the clicker controls:
see the README at the repository root.
